기본 글자

b : 굵은 글자

strong : 중요한 내용 (굵게 표시)

i : 기울인 글자

em : 강조 (기울여 표시)

u : 밑줄

s : 취소선

mark : 형광펜 표시

small : 작은 글자

code : 컴퓨터 코드

sup : 위 첨자 → x2 + y2 = r2

sub : 아래 첨자 → H2O, CO2

b와 strong의 차이

둘 다 굵게 보이지만 b는 모양만 굵게, strong은 "중요하다"는 의미를 가집니다. 화면 낭독기는 strong을 강조해서 읽어 줍니다. i와 em의 관계도 같습니다.
