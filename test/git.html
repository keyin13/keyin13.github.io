Git 사용법

Git은 파일의 변경 이력을 기록하는 버전 관리 시스템입니다. GitHub에 올리면 다른 컴퓨터에서 내려받거나 GitHub Pages로 웹호스팅할 수 있습니다.

1. 처음 한 번만 하는 설정

git config --global user.name "홍길동"
git config --global user.email "you@example.com"

2. 저장소 만들고 첫 커밋하기

cd 내프로젝트폴더
git init                  # 현재 폴더를 Git 저장소로 만든다
git add .                 # 모든 변경 파일을 스테이지에 올린다
git commit -m "첫 커밋"    # 스테이지의 내용을 기록한다

3. GitHub에 올리기

GitHub에서 빈 저장소(repository)를 만든 뒤 주소를 복사해 연결합니다.

git remote add origin https://github.com/아이디/저장소이름.git
git branch -M main
git push -u origin main

4. 수정 후 다시 올리기

git status                # 바뀐 파일 확인
git add .
git commit -m "3장 예제 추가"
git push

5. 다른 컴퓨터에서 받기

git clone https://github.com/아이디/저장소이름.git   # 처음 받을 때
git pull                                             # 최신 내용 가져오기

6. GitHub Pages로 웹호스팅

  1. GitHub 저장소 → Settings → Pages로 이동합니다.
  2. Source를 Deploy from a branch, Branch를 main / (root)로 지정하고 저장합니다.
  3. 잠시 후 https://아이디.github.io/저장소이름/ 주소로 접속합니다. 첫 화면은 index.html입니다.
